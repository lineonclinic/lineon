# 라인온의원 · 온라인 시술실

말없이 같이 누워 있는 온라인 시술실. 빈 베드에 누우면 Dr. Oh가 와서 스킨부스터를 놔 드립니다.

- `index.html` — 페이지
- `app.js` — 3D 시술실 (Three.js), 시술 연출, 실시간 동접(Supabase Realtime)
- `config.js` — Supabase 주소/공개키, 카카오 채널 링크, BGM 경로, 방 정원
- `assets/` — 로고(SVG), 파비콘, BGM(`bgm.mp3`를 넣으면 재생)
- `vendor/three.module.js` — Three.js r170

GitHub Pages로 그대로 배포됩니다 (빌드 불필요).
